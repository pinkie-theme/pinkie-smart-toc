# 🌸 Pinkie Smart TOC for AI Chats 🌸

> **Your sweet, gorgeous, and smart Table of Contents sidebar with real-time text-highlight saver for ChatGPT, Gemini, Grok, and Claude.** Built with love for developers, creators, and AI enthusiasts! (´｡• ᵕ •｡`) ♡

---

## 🌟 Introduction

**Pinkie Smart TOC** is a feature-packed, premium Chrome Extension designed to bring order, beauty, and powerful bookmarking capabilities to your web AI conversations. It overlays a glassmorphic sliding sidebar on your favorite AI websites, instantly structuring long chats into interactive navigators.

---

## ✨ Outstanding Features

| Feature | Description |
| :--- | :--- |
| **❓ Asked Tab** | Lists all your questions sequentially. Click a card to scroll directly to the prompt with a smooth, glowing pink highlight. |
| **✨ Answered Tab** | Instantly displays AI responses, helping you skim and skip long code segments with ease. |
| **📌 Pinned Tab** | Bookmark critical parts of the conversation. Pins are persistently stored using `chrome.storage` and survive tab reloads! |
| **🖍️ Highlights Notebook** | Drag your cursor to select any text/code on the screen, click the adorable floating **`Lưu highlight 🖍️`** tooltip, and save snippets directly to your sidebar collection! |
| **🔍 Live Search Input** | Real-time fuzzy filtering of questions, answers, and highlights as you type. |
| **☀️/🌙 Theme Switcher** | Cycle instantly between a beautiful **Pastel Pink Light Mode** and a neon **Midnight Deep Pink Dark Mode**. |
| **↔️ Position Swapper** | Swing the sidebar and toggle trigger button seamlessly between the **Left** and **Right** of your screen. |
| **🌐 Translation Packs** | Instant interface localization. Swap between **Tiếng Việt 🇻🇳** and **English 🇬🇧** in one click. |
| **⌨️ Global Alt+Q Key** | Hide or show your sidebar instantly using the configurable hotkey shortcut. |

## 📦 How to Install (Unpacked Developer Mode)

Since this extension is optimized for your custom Obsidian environment and personal usage, you can load it directly into Google Chrome in just a few seconds:

1. **Open Google Chrome** and navigate to `chrome://extensions/`.
2. **Enable Developer mode** by toggling the switch in the top-right corner.
3. Click the **Load unpacked** button in the top-left corner.
4. Select the cloned **`pinkie-smart-toc`** repository folder.
5. *Boom!* (｡♥‿♥｡) The adorable cherry blossom icon `🌸` will appear in your extension toolbar. Open ChatGPT, Gemini, Claude, or Grok to start navigating in absolute style!

## ⌨️ Custom Shortcuts Configuration

* **Show/Hide Sidebar**: Press **`Alt + Q`** at any time.
* **Selection Save**: Select any text on screen and click the floating bubble button.
* **Clipboard Copy**: Inside the Highlight list, click **`📋`** (it will temporarily animate to a green checkmark **`✅`** for 1.2s to visually confirm the copy).
